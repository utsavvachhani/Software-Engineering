## ✅ Functional Requirements

- User Registration and Email Activation  
- Secure Login with Lockout Mechanism  
- Membership Plans with UPI/Card Payments  
- Session Booking with Real-time Trainer Availability  
- Feedback and Review System  
- Profile Management with Fitness Goals  
- Admin Report Generation (PDF/Excel)  
- Inventory and Equipment Management  
- Role-Based Access Control (Admin/Trainer/Member)

---

## 🔒 Non-Functional Requirements

- User-Friendly UI (Mobile & Desktop)  
- Performance: Supports 10,000 concurrent users  
- Security: SSL, Dual Authentication, Secure Payment Protocols  
- Uptime ≥ 99.9%, Weekly Backups  
- Scalable Infrastructure  
- Compliance with Legal/Privacy Policies  
- Modular and Maintainable Codebase  
- Portable Across OS (Windows, macOS, Linux) and Browsers
